# SESA Raccolta Rifiuti per Home Assistant

Integrazione custom per Home Assistant che legge il calendario raccolta rifiuti direttamente da `app.sesaeste.it`.

## Funzioni

- Configurazione da UI
- Comuni e vie caricati live dal sito SESA
- Calendario Home Assistant nativo
- Sensori:
  - Raccolta oggi
  - Raccolta domani
- Download calendario annuale completo
- Nessun polling continuo verso SESA
- Refresh manuale calendario
